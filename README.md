# The-Canon-Event---SPACE-MISSION-GAME-DESIGN

Echoes Beyond is a 2D sci-fi survival game about a survivor searching for a cure after Earth is devastated by a zombie outbreak. The player explores a laboratory and spacecraft, then travels between planets to gather what’s needed to save Earth.

The planned journey is Earth → spacecraft → Mars → spacecraft → Europa → spacecraft → Pluto → spacecraft → Titan → spacecraft → Earth. Each planet has its own environment and mission. The game includes movement, enemies, health hazards, resource collection, spacecraft travel, and story messages.
